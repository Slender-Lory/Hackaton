# Frontend — Vue 3 + JavaScript + Vite + Pinia + SCSS

Документация и правила написания кода — в [`docs/frontend/`](../docs/frontend/README.md): архитектура, стандарты JS, Vue и SCSS (БЭМ), тесты, дизайн-система.

```bash
npm install
npm run dev      # http://localhost:5173, /api проксируется на http://localhost:8080
npm run format   # Prettier
npm run lint
npm test
npm run build
```
