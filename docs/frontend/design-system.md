# Дизайн-система: «коллекционные карты»

## Идея

Профессии — коллекционные карты на игровом столе. Открытая карта ветеринара с живым 2D-пациентом, остальные лежат рубашкой вверх. Выбор профессии — розыгрыш карты.

Аудитория — подростки 14–16 лет: ярко и современно, но без детскости (никаких мультяшных глаз, конфетти, кислотной радуги, Comic Sans, эмодзи вместо иконок).

## Токены

Все значения — в [`vars.scss`](../../frontend/src/assets/styles/vars.scss).

| Роль               | Переменные                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------ |
| Стол (фон страниц) | `$color-playmat`, `-deep`, `-light`, `-line`                                                     |
| Текст на столе     | `$color-on-playmat`, `$color-on-playmat-soft`                                                    |
| Лицо карты         | `$color-card-face`, `$color-card-text-box`, текст — `$color-ink`, `$color-ink-soft`              |
| Рубашка карты      | `$color-card-back`, `$color-card-back-pattern`                                                   |
| Главное действие   | `$color-action` (жёлтый), `-deep`, `-light`                                                      |
| Угроза, ошибка     | `$color-danger`, текст ошибки — `$color-danger-text`                                             |
| Цвет профессии     | `$professions` → `--profession-<код>` → `--accent` → `$color-accent`                             |
| Шрифты             | `$font-display` (Dela Gothic One — названия, заголовки), `$font-primary` (Onest — всё остальное) |
| Скругления         | `$radius-chip`, `$radius-button`, `$radius-card`, `$radius-card-inner` — разные по иерархии      |
| Тени               | `$shadow-card`, `$shadow-card-lifted`, `$shadow-button` — мягкие, со смещением                   |

## Компоненты `Ui*`

| Компонент           | Назначение                                                                                                                                                                                                                    |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `UiButton`          | `theme`: `action` — жёлтая главная кнопка (одна на экран), `ghost` — второстепенная на столе, `quiet` — второстепенная на лице карты, `danger` — необратимое действие (выход, удаление). `large`, `fluid`, `disabled`, `type` |
| `UiField`           | поле формы с подписью и ошибкой: `v-model`, `label`, `error`, атрибуты `<input>`                                                                                                                                              |
| `UiModal`           | окно на Reka UI Dialog: `title`, `description`, `wide` (широкое, для длинного содержимого вроде паспорта пациента), событие `close`; длинное окно прокручивается                                                              |
| `UiProgress`        | полоска прохождения в цвете профессии                                                                                                                                                                                         |
| `Inspira/GlareCard` | наклон карты и голографический блик за курсором                                                                                                                                                                               |

Карточная графика — миксины `card-face` и `card-back`, чипы — миксин `chip`.

Новый общий элемент интерфейса → `components/Ui/UiThing.vue` и строка в эту таблицу.

## Тексты

- Коротко: одна мысль — одна строка, подростки длинное не читают.
- Обычный регистр предложения; без КАПСА в подписях и без «надзаголовков» над заголовками.
- Кнопка называет действие: «Начать смену», «Начать первую смену», а не «Ок»/«Далее» без контекста.
- Ошибка говорит, что не так и как исправить: «Минимум 2 символа».
- Не обещаем того, чего нет в игре.

## Анимации

- Одна авторская анимация на экран: раздача карт на главной, смена сцен в прологе.
- Остальное — отклик на действие: нажатие кнопки, подпрыгивание закрытой карты, вздрагивание пациента по клику.
- Без бесконечных декоративных пульсаций и одинаковых «въездов» у каждого блока.
